# 4th-MAVIC-T

## Refined Dataset (`MACIV-T-2025-Structure-Refined`)

Root: `datasets/BiliSakura/MACIV-T-2025-Structure-Refined`

Layout: `{task}/train/{input,target}/`

Generated by `scripts/prepare_refined_dataset_crop.py`.

| Task | Resolution | Input | Target |
|------|------------|-------|--------|
| `sar2eo` | 256x256 | SAR 1-band PNG (symlink) | EO 1-band PNG (symlink) |
| `rgb2ir` | 1024x1024 | RGB 3-band TIFF | IR 1-band TIFF |
| `sar2ir` | 1024x1024 | SAR 1-band TIFF | IR 1-band TIFF |
| `sar2rgb` | 1024x1024 | SAR 1-band TIFF | RGB 3-band TIFF |

- Filenames encode `{city}__{tile}__{source}__{modality}.tif` (crop suffixes may be appended).
- Manhattan `uint16` is normalized to `uint8` during preprocessing.
- Manifest: `manifests/refined_manifest.csv` with columns `task, split, input, target, tile, source_city`.
- Full set only; no explicit train/val split inside the refined set.

## Evaluation Inputs (Original `MAVIC-T-2025`)

- Validation inputs: `datasets/BiliSakura/MAVIC-T-2025/val/{rgb2ir,sar2ir,sar2rgb}`
- Test inputs: `datasets/BiliSakura/MAVIC-T-2025/test/{rgb2ir,sar2ir,sar2rgb,sar2eo}`
- These folders contain inputs only (no targets) for inference/evaluation.

## Dataset Loader

Use the HuggingFace `datasets` wrapper at `src/mavic_t_dataset.py` to load refined train data and original val/test inputs.
